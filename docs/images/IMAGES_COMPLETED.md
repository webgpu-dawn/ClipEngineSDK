## 📝 使用说明

### 在 Markdown 中引用

```markdown
<!-- Logo -->
![ClipEngine Logo](docs/images/clipengine-logo.svg)

<!-- 架构图 -->
![系统架构](docs/images/architecture.svg)

<!-- 性能对比 -->
![性能对比](docs/images/render-performance.svg)
```

### 在 HTML 中使用

```html
<!-- 直接嵌入 -->
<img src="docs/images/clipengine-logo.svg" width="400" alt="ClipEngine Logo">

<!-- 居中显示 -->
<p align="center">
  <img src="docs/images/architecture.svg" width="800" alt="系统架构">
</p>
```

### 转换为 PNG/JPG

如果需要位图格式（例如用于 PPT）：

```bash
# 使用 Inkscape
inkscape architecture.svg --export-type=png --export-width=1920

# 或使用在线工具
# https://cloudconvert.com/svg-to-png
```
